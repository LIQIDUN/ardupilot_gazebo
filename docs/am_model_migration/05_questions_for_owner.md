# 05 需要用户确认的问题（按优先级）

所有问题均属于 **[用户确认]**。本篇不是要求立即批准一个尚未确定的模型，也不将未回复视为同意。P0 决定能否设计正确的拓扑和安装变换；P1 决定控制与外部接口；P2 用于第二阶段实物参数和验收。

## P0-1：实际拆除的刚体和第一轴

旧 `base_link` 是有质量的静止实体，`joint_1` 是连接它与 `link_1` 的受控转动轴，channel 6 指向该轴（机械臂 SDF :3–35；飞机 SDF :522–535）。请确认改造后：

- 仅拆掉旧外壳/支架，但第一轴及其定子、转子仍存在；还是实际取消第一轴？
- 第一轴若保留，哪个实际刚体固定到飞机，哪个实际刚体相对它转动？请用现有 Link 对照实物/CAD 命名。
- “第一个连杆”是否对应旧 SDF 的 `link_1`、改造后的其他刚体，还是一个包含固定部分与活动部分的新组件？

**影响**：保留 joint_1 需要有效固定父刚体；把原活动 link_1 固定焊接到飞机会消除该轴。若实物取消该轴，需要您明确确认自由度变化及 channel 6 后续处理。不能由“删除 base_link”推断“删除 joint_1”。

## P0-2：目标位姿两端的坐标系和成立条件

目标 `0 0 -0.044 π 0 0` 中：

- 飞机参考系是否就是当前 SDF 的飞机模型系/飞机 base_link？当前二者重合，但与质心系不同；还是您指 CAD 安装基准或飞控 FRD 系？
- 新机械臂安装参考系的原点具体位于哪个实体的哪个物理位置，X/Y/Z 朝向如何定义？请给出它与现有 SDF 某个 Link/Joint 系的关系。
- 该目标是固定安装根在所有关节角下都满足，还是仅在指定零位（例如 joint_1=0）时满足？

**影响**：若参考系就是旧 link_1 零位，旧内部 +30 mm 偏移会使 include 的正确补偿不同；若它是 joint_1 的活动子体，不能既保持自由转动又要求相对飞机朝向始终固定。最终根的名称和 `T_NR` 必须在这里确定。

## P0-3：首段改造后的几何与零位

请提供改造后第一段到下一关节的尺寸、轴心位置、轴方向和零位朝向，尤其是旧 joint_1→link_1 以及 link_1→joint_2 的关系是否保留。若新 Mesh 原点不同，请给出 CAD 坐标到安装参考系的变换。

**影响**：决定是否可保持 joint_2–5 局部 pose、Link 内 Mesh pose 和轴方向。只有新的安装位置不能确定新的运动学链。不要用旧 Mesh 文件名推定新参考系。

## P1-1：保留的机械臂自由度、夹爪及控制映射

请确认 joint_1–5 中实际保留哪些轴，轴正方向和机械零位是否改变，以及是否保留 SDF 当前双指夹爪。现状是五转动轴通道 6–10、两移动指共通道 11；指爪轴相反、没有 mimic 约束。是否继续使用这组映射？是否有单独的实机舵机输出、限位和标定表？

**影响**：保留关节名可以减少插件改动；若取消某轴也不能自动挤占或重排后续编号。当前 Gazebo 通道表不证明实机输出编号/功能。

## P1-2：ROS/规划所需 URDF 与末端参考

是否继续用 `model.urdf` 做 robot_state_publisher、RViz、IK 或控制？新末端的 TCP 定义、法兰到夹爪尖点偏移是多少？是否保留 tool0 的含义？

**影响**：当前 URDF 没有双指爪且 link_5 动力学不同；ROS WorldObserver 还使用旧完整 Link 名和 82 mm 末端偏移（01 中列出确切路径/行号）。需确认是同步出一份可运行的新 URDF，还是仅保留来源存档。SDF 路径自包含不能替代 ROS 包路径自包含。

## P1-3：新实例在世界和 ROS 中的名称

模型目录/内部名固定为 `am`。验证时希望世界中直接实例化名为 `am` 的模型，还是保留一个明确命名的外层包装实例？新旧模型是否需要同场景并存？

**影响**：决定 IMU scoped 后缀、ModelStates 名称、LinkStates 完整名称、观察器配置和 SITL 端口隔离。建议单独新验证世界和新入口，旧世界保留，避免批量替换历史证据路径。

## P2-1：第二阶段动力学测量边界

请在测量完成后提供每个实际刚体的 mass、COM、惯量六分量与对应坐标系，说明安装支架、首轴定子/转子、线缆、夹爪基座、指爪和负载如何分配。是否有 CAD 导出的主轴旋转和惯量数据？

**影响**：删除旧根会直接移除现有 0.34432 kg，不会自动并入飞机或新根；link_5 现有惯量有人为调整，四桨还有物理主惯量三角关系问题。只有统一测量后才能更新，不能让复制基线代表新实物参数。

## P2-2：碰撞保真和验收环境

当前机械臂没有有效 collision，飞机机身和桨的 collision 也被注释。后续希望何时补齐碰撞几何？部署是否固定为本机 Gazebo 11.15.1/libsdformat 9.10.1，还是需要跨机器打包？请明确安装变换的数值容差、实物安装误差容差，以及首轮验证是否限定为暂停加载/无飞控。

**影响**：碰撞修改和实物惯量更新应与纯复制基线分开验收；跨机器交付需明确 Gazebo/ROS、材质和插件依赖。SDF 检查通过、暂停模型能加载、SITL 能控制和实机可运行是不同级别的证据。

## 建议优先答复格式

可以先回答以下四项，P1/P2 信息暂缺时保持待确认：

1. joint_1 是否保留；固定部分和活动部分分别对应哪个实际刚体。
2. 新安装参考坐标系属于哪个实际连杆；原点、轴方向及与旧模型的变换。
3. 飞机参考系是否为当前飞机 base_link；目标位姿是否只在机械臂零位成立。
4. 第一段改造到 joint_2 的尺寸、轴心和朝向是否改变。
